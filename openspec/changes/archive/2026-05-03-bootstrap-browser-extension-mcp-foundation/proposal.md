## Why

当前仓库仅完成了 OpenSpec 初始化，尚未具备浏览器插件项目所需的基础工程能力。为了让后续功能规格能够在稳定、一致、可扩展的环境中实现，需要先搭建一个基于 Vue 3 与 Element Plus 的浏览器插件基础架构，并定义插件界面与 Chrome MCP 页面读写能力之间的协作边界。

## What Changes

- 初始化浏览器插件项目基础架构，包含适合后续扩展 Popup / 独立页面等 UI 入口的工程目录与构建约定。
- 建立基于 Vue 3 + Element Plus 的简单交互界面，用于展示连接状态、页面读取结果与页面写入操作入口。
- 抽象 Chrome MCP 服务访问层，统一处理页面读取、页面内容写入、错误反馈与权限相关状态。
- 定义插件 UI、MCP 访问层与页面操作模型之间的职责边界，为后续按 spec 逐步补充业务能力做准备。
- 为后续 capability 扩展预留结构，包括可新增页面操作、状态管理、消息桥接与多入口 UI 的能力。

## Capabilities

### New Capabilities
- `extension-foundation`: 定义浏览器插件项目的基础工程结构、UI 入口组织方式、通用状态与错误处理约定。
- `chrome-mcp-page-io`: 定义插件通过 Chrome MCP 服务读取当前页面信息并执行页面写入操作的交互能力与边界。

### Modified Capabilities
- None.

## Impact

- 新增浏览器插件工程基础目录、前端入口与通用配置。
- 引入 `Vue 3` 与 `Element Plus` 作为界面技术栈，并确定与浏览器插件构建方案兼容的依赖与脚手架选择。
- 新增 Chrome MCP 服务访问抽象层、页面读写接口定义、错误处理与状态展示约定。
- 为后续实现可能涉及的构建工具、插件权限配置、消息通信与测试基建打下基础。
